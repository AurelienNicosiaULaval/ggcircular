# Roadmap

Implemented in version 0.2.0:

1. Optional integration with the `CircularRegression` package.
2. `autoplot()` methods for angular models.
3. Circular residual diagnostics.
4. Support for mixtures of von Mises distributions.
5. Large-sample and bootstrap confidence intervals for circular means.
6. Annotated circular tests on graphics.
7. Basic support for spherical data.
8. Optional integration with `momentuHMM`.
9. Visualization of angle distributions by latent state.
10. Support for Bayesian circular posterior draws.

Future refinements:

1. More formal validation against published circular regression examples.
2. More rigorous small-sample intervals for circular means.
3. Additional spherical distributions and visualization layers.
4. More specialized posterior workflows for Stan, brms and rstanarm objects.
5. More extensive `momentuHMM` examples using fitted models in long-running vignettes.
