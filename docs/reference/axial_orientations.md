# Simulated axial orientations

Simulated axial orientation data, such as fiber or fault orientations,
stored modulo `pi`.

## Usage

``` r
axial_orientations
```

## Format

A tibble with 300 rows and 3 variables:

- sample:

  Sample identifier.

- orientation:

  Axial orientation in radians, modulo `pi`.

- group:

  Group label.

## Source

Simulated for package examples.
