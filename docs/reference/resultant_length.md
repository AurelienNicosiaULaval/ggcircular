# Resultant length

Resultant length

## Usage

``` r
resultant_length(x, axial = FALSE, na.rm = TRUE)
```

## Arguments

- x:

  Numeric vector of angles in radians.

- axial:

  Should the data be treated as axial, modulo `pi`?

- na.rm:

  Should missing values be removed?

## Value

The sample resultant length `R`.
