# Simulated hourly activity

A reproducible simulated dataset of hourly activity converted to
circular angles.

## Usage

``` r
hourly_activity
```

## Format

A tibble with 240 rows and 5 variables:

- id:

  Individual identifier.

- hour:

  Hour of day.

- angle:

  Hour converted to radians.

- activity:

  Activity level.

- group:

  Group label.

## Source

Simulated for package examples.
