# Check an angle vector

Check an angle vector

## Usage

``` r
check_angle(x, allow_na = TRUE)
```

## Arguments

- x:

  Object to check.

- allow_na:

  Should missing values be allowed?

## Value

Invisibly returns `x` if the check succeeds.
