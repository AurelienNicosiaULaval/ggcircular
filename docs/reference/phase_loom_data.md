# Compute phase loom data

Discretizes circular-linear observations into angular sectors and linear
bins and returns binned mass flows for phase loom displays.

## Usage

``` r
phase_loom_data(
  theta,
  x,
  n_sectors = 48,
  n_x_bins = 24,
  min_mass = 0.002,
  max_flows = 180,
  mass_type = c("joint", "conditional")
)
```

## Arguments

- theta:

  Angles in radians.

- x:

  Real-valued response.

- n_sectors:

  Number of angular sectors.

- n_x_bins:

  Number of linear bins.

- min_mass:

  Minimum mass to retain.

- max_flows:

  Maximum number of flows to retain. Use `NULL` to keep all.

- mass_type:

  Either `"joint"` for joint masses or `"conditional"` for masses
  normalized within each angular sector.

## Value

A data frame with sector identifiers, endpoints and mass values.
