# Support

Use the GitHub issue tracker for:

- reproducible bug reports;
- documentation problems;
- feature requests;
- questions about package behavior;
- validation examples that could improve the package.

For statistical methodology questions, include enough context to distinguish a
package bug from a modelling or interpretation question. Minimal code, small
data examples and the expected output are the most helpful.

For private matters, use the maintainer email listed in `DESCRIPTION`.
